# 创建与恢复存档

import Screenshot from '@site/src/components/Screenshot';

## 创建存档

选择游戏，填写描述，点击 **创建新快照**。可通过搜索描述、点击日期列排序来查找存档。

<Screenshot src="/img/guide/snapshots.png" alt="存档列表" caption="当前存档点在列表中高亮" />

## 恢复存档

1. 退出游戏。
2. 点击存档右侧的 **应用**，或顶部的 **应用最新快照**。
3. 确认恢复后，重新启动游戏。

需要修改描述或删除存档时，使用该条目右侧的操作按钮。勾选多条存档可批量操作。

## 额外备份

恢复前默认保留一份额外备份。在游戏右上角菜单中打开 **额外备份**，选择需要找回的存档。

额外备份保存在本机，默认每个游戏保留 5 份，设为 0 可保留全部。

## 备份设置

在 **设置 → 备份设置** 中调整恢复确认、额外备份、压缩级别和哈希校验。

<Screenshot src="/img/guide/backup-settings.png" alt="备份设置" />

可选择 **不压缩**、**优先速度**、**均衡**（默认）或 **优先体积**。设置用于之后创建的存档。

## 不使用软件时恢复

新备份是普通 `.7z` 文件，例如 `2026-10-07_18-30-00_a1b2c3d4e5f6.7z`。时间方便查找，随机后缀区分同一时间创建的备份。

1. 退出游戏，用 7-Zip 等工具解压备份。
2. 阅读 `RESTORE.txt`，核对游戏、备份时间、备注和原设备的存档位置。
3. 保留当前存档的副本，再将解压出的文件或文件夹复制到本设备对应的位置。`_rgsm` 是识别信息，不需要复制到游戏目录。

存档保留自然文件名和相对目录；同名位置会分开保存。注册表备份使用标准 `.reg` 文件，核对键路径后才能导入。更换设备或账号时，应使用本设备实际位置，不能直接照搬说明里的原设备路径。

单个新归档包含恢复所需说明，无需依赖 `Backups.json`。旧备份可通过[升级本地旧备份](../help/upgrade.mdx#升级本地旧备份)转换；缺失的时间或位置信息会明确标记，不会伪造。

# 自动备份

import Screenshot from '@site/src/components/Screenshot';

在游戏右上角菜单中打开 **自动保存设置**。

## 定时备份

1. 开启 **定时备份**。
2. 选择备份间隔，设置最大定时备份数。数量留空时使用全局设置。
3. 点击 **保存设置**。

## 按游戏运行状态备份

1. 开启 **进程监控**，选择游戏进程。
2. 勾选 **启动时**、**退出时** 或 **运行中定时**。
3. 按需设置间隔，点击 **保存设置**。

侧栏游戏前的绿色小点表示已启用自动备份。使用时请保持存档管理器运行。

# 存档位置与路径变量

## 修改存档位置

1. 打开游戏页面，点击 **查看受管理文件**。
2. 选择设备，编辑存档位置或添加条目。
3. 点击 **保存**。

支持文件、文件夹和 Windows 注册表项。恢复文件夹时，可按需启用“应用前删除”，先清空该位置再恢复。

## 使用路径变量

在路径输入框中输入 `<`，从提示中选择变量。输入框会显示本机解析后的路径。

例如 `<home>/Saved Games/MyGame` 使用当前用户目录。

自动识别的动态路径会按当前设备匹配文件。可在 **设置 → 自动扫描** 中补充游戏库目录和安装位置。

## 多个游戏库时怎么选

`<root>` 表示游戏库根目录，后面的相对路径会原样拼接。例如游戏在 `H:\Dying Light\DyingLightGame.exe`，库目录是 `H:\`，启动路径可填写 `<root>/Dying Light/DyingLightGame.exe`。

如果有多个候选位置，在添加游戏或导入窗口中选择该游戏使用的库；已添加的游戏可在 **查看受管理文件 → 游戏根目录** 中修改。只有一个候选时会自动使用，无需选择。程序不会根据文件是否存在替你选库。

选择和路径一起保存，仅用于这个游戏、这台设备。另一台设备可以使用不同的库目录，路径中的相对部分保持不变。启动文件需要唯一位置；动态存档路径可以明确选择多个库或账号。

路径下方可查看解析结果。提示“请选择位置”时先完成选择；提示文件不存在时，检查路径，或运行游戏生成存档后再备份。也可以直接使用文件选择器填写实际路径。

## 设备路径

在 **设置 → 设备管理** 中为设备命名。需要复用其他设备的路径时，点击对应设备的 **导入路径**，确认后会覆盖本机的相应路径设置。

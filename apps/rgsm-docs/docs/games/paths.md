# 存档位置与路径变量

## 修改存档位置

1. 打开游戏页面，点击 **查看受管理文件**。
2. 选择设备，编辑存档位置或添加条目。
3. 点击 **保存**。

支持文件、文件夹和 Windows 注册表项。恢复文件夹时，可按需启用“应用前删除”，先清空该位置再恢复。

## 使用路径变量

在路径输入框中输入 `<`，从提示中选择变量。输入框会显示本机解析后的路径。

例如 `<home>/Saved Games/MyGame` 使用当前用户目录。

自动识别的动态路径会按当前设备匹配文件。可在 **设置 → 自动扫描** 中补充游戏库目录和安装位置。

## 手动输入与通配符

**添加存档文件 / 文件夹** 会新增可编辑条目；路径右侧的 **选择路径** 才会打开文件选择器。手动路径、动态路径和设备覆写都支持相同的变量与通配符。

例如 `D:/Saves/*/SaveGames` 会备份所有匹配目录，恢复时保留它们各自的相对目录。通配符不会把不同目录自动视为同一份存档。“打开”会打开精确位置，或通配符集合所在的根目录。

## 不同设备使用不同账号目录

在添加或修改游戏时，在 **路径变量** 中配置变量，并在路径中填写 `<var:变量名>`，例如 `<var:saveRoot>/MyGame/<var:account>/*.sav`。

- 直接修改变量值，只为当前设备上的本游戏设置值；每项旁边显示当前值的来源。
- 在变量右侧的 **⋯** 菜单选择 **编辑设备变量…**，查看受影响的游戏并编辑共享值。已有游戏覆盖保持不变。
- 菜单中的 **改用设备变量** 清除游戏覆盖；**撤销默认值修改** 仅撤销本次对共享值的修改。
- 取消编辑不保存；保存时变量与游戏配置一起保存。

另一台设备为同名变量填写它自己的值。恢复会使用目标设备上的值，通配符匹配的不同存档仍分别保留。变量值是实际文本或路径，不支持嵌套变量、通配符或脚本；值里的通配符字符按普通字符处理。缺少引用的变量值时会提示补齐。

如果变量位于通配符之后，新备份会使用归档 V5 保存可重定位信息，这类备份需要支持 V5 的版本恢复。已有备份仍可读取，但不会推断旧目录名对应哪个变量。

## 多个游戏库时怎么选

`<root>` 表示游戏库根目录，后面的相对路径会原样拼接。例如游戏在 `H:\Dying Light\DyingLightGame.exe`，库目录是 `H:\`，启动路径可填写 `<root>/Dying Light/DyingLightGame.exe`。

如果有多个候选位置，在添加游戏或导入窗口中选择该游戏使用的库；已添加的游戏可在 **查看受管理文件 → 游戏根目录** 中修改。只有一个候选时会自动使用，无需选择。程序不会根据文件是否存在替你选库。

选择和路径一起保存，仅用于这个游戏、这台设备。另一台设备可以使用不同的库目录，路径中的相对部分保持不变。启动文件需要唯一位置；动态存档路径可以明确选择多个库或账号。

可在路径下方或悬停状态点查看解析结果。提示“请选择位置”时先完成选择；提示文件不存在时，检查路径，或运行游戏生成存档后再备份。也可以直接使用文件选择器填写实际路径。

## 设备路径

如果某台设备的存档位置不符合原始动态路径，可以单独覆写：

1. 打开 **查看受管理文件**，选择设备。
2. 在动态存档条目开启 **覆写此设备路径**，填写实际路径。
3. 点击 **保存**。需要恢复原规则时，关闭 **覆写此设备路径** 并保存。

![为单个存档条目开启设备路径覆写](../../../../docs/screenshots/device-path-override.png)

覆写只影响所选设备，原始动态路径保持不变。备份、恢复和自动备份都使用覆写路径；该位置不存在时，备份会报错，不会改用其他位置。恢复可以创建尚不存在的目标。

覆写只修改路径，不改变文件或文件夹类型；同一存档条目包含多个位置的快照不能合并恢复到单个覆写位置。

在 **设置 → 设备管理** 中为设备命名。需要复用其他设备的路径时，点击对应设备的 **导入路径**，确认后会覆盖本机的相应路径设置。

在路径输入框旁点击 **插入变量**，可选择已有变量，或填写名称和值后新建并插入。无需手动输入 `var:`。设备变量供当前设备上的游戏共用；游戏变量只影响当前设备上的本游戏。另一台设备缺少变量时，游戏页提供 **设置变量** 入口。备份或恢复时也会先引导填写，选择 **保存并继续** 后继续原操作，关闭则取消该操作。

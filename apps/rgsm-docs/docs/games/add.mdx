# 添加与自动识别

import Screenshot from '@site/src/components/Screenshot';

## 手动添加

1. 点击左侧 **添加游戏**，填写游戏名称。
2. 添加存档文件夹、文件或 Windows 注册表项。
3. 按需选择游戏启动文件，点击 **保存**。

<Screenshot src="/img/guide/add-game.png" alt="添加游戏" caption="一个游戏可以添加多个存档位置" />

## 自动识别本地游戏

1. 在添加游戏窗口点击 **自动识别本地游戏**。
2. 搜索并勾选游戏，查看识别出的存档位置。
3. 确认要导入的条目，完成添加。

支持一次导入多个游戏。在 **设置 → 自动扫描** 中更新识别数据库、添加游戏库目录。

## 扫描视觉小说

在 **设置 → 自动扫描** 中添加视觉小说扫描目录，再点击添加游戏窗口中的 **自动扫描视觉小说**。

# 反馈问题

推荐在 [GitHub 提交 Issue](https://github.com/mcthesw/game-save-manager/issues/new/choose)。请带上：

- 软件版本、操作系统，以及安装版或便携版。
- 做了什么、原本期望什么、实际发生了什么。
- 能复现问题的步骤和错误截图。
- 对应时间的日志；在 **设置 → 通用 → 打开日志文件夹** 中获取。

云同步问题请补充存储类型、涉及的设备及各自的现象。

发送前请隐藏凭据和个人信息。涉及存档丢失时，先保留本机和云端数据。

功能建议也可以通过 Issue 或[讨论区](https://github.com/mcthesw/game-save-manager/discussions)提出。其他联系方式见[关于](./about.mdx)。

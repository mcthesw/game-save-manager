# 副本与清理

## 上传与下载

在游戏存档列表中，使用条目右侧的 **上传到云端** 或 **下载到本设备**。勾选多条存档可批量操作。

| 副本位置 | 操作 |
| --- | --- |
| 本机有副本 | 直接应用 |
| 云端有副本 | 下载后应用 |
| 其他设备有副本 | 在该设备上传后，再下载 |

## 删除副本

| 操作 | 范围 |
| --- | --- |
| 移除本机副本 | 移除本设备的备份文件，保留历史记录 |
| 从云端移除 | 移除云端的备份文件，保留历史记录 |
| 从所有设备和云端删除 | 永久删除存档点与各端副本，离线设备重连后执行 |

移除副本前，请确认其他位置还有可用副本。

## 清理自动存档

在游戏的 **自动保存设置** 中设置 **共享自动快照上限**，按进度线永久清理旧自动存档及各端副本。

手动、快捷操作、各设备当前位置和已保护的存档点会保留。

## 移除游戏

**在本设备停止管理**保留共享历史和已有备份。**永久删除共享游戏**会删除整个游戏的共享历史和各端副本。

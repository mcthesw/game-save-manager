# 在另一台设备接着玩

import Screenshot from '@site/src/components/Screenshot';

## 在原设备保存

1. 结束游戏，创建一个存档点。
2. 确认文件已上传。使用 **云备份** 或 **多设备同步** 时，新存档会自动上传。

## 在新设备继续

1. [连接同一份云端资料库](../extras/cloud.mdx)，设置游戏在本机的存档位置。
2. 打开 **同步**，点击游戏的 **比较进度** 入口。
3. 找到要继续的存档，点击 **使用此进度** 并确认。
4. 等待应用完成，启动游戏。

<Screenshot src="/img/guide/progress.png" alt="比较设备进度并选择存档" caption="比较进度" />

应用时请关闭游戏。软件会先下载、校验存档，并为本机已有存档创建安全备份。

## 两边都产生了新进度

在比较窗口中查看两边的描述和分支关系，选择 **保留本机进度** 或 **使用此进度**。也可选择 **稍后决定**。

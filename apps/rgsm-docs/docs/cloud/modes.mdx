# 同步模式

import Screenshot from '@site/src/components/Screenshot';

在 **同步** 页开启游戏的云同步，点击 **同步方式** 选择模式。

| 模式 | 用途 |
| --- | --- |
| 手动 | 共享存档记录，手动上传、下载和恢复 |
| 云备份 | 新建存档时自动上传 |
| 多设备同步 | 新建存档时自动上传，并提示其他设备的可用进度 |

每台设备可为各游戏单独选择模式。

<Screenshot src="/img/guide/cloud-library.png" alt="同步模式与存档副本分布" />

云端信息按设置中的自动同步间隔更新，切换游戏时沿用已有信息。

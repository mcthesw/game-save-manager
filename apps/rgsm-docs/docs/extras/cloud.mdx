# 连接云存储

支持 **WebDAV** 和 **S3 兼容存储**，如坚果云、MinIO、Cloudflare R2。

## 填写连接信息

1. 打开 **同步 → 云端设置**。
2. 选择存储类型，填写连接信息。
3. 测试连接并保存。

| 存储类型 | 连接信息 |
| --- | --- |
| WebDAV | 服务器地址、账号、密码或应用密码 |
| S3 | Endpoint、Bucket、Region、Access Key ID、Secret Access Key |

使用 S3 前需创建存储桶。参与同步的设备使用相同的云端根路径。

## 连接资料库

空位置按提示创建资料库，已有的兼容资料库会自动连接。旧版资料库请按[升级说明](../help/upgrade.mdx)迁移。

连接完成后，为游戏[选择同步模式](../cloud/modes.mdx)。

## 在另一台设备上继续

按[跨设备接续流程](../cloud/progress.mdx)保存、上传并应用进度。

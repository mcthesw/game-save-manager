# 界面与设备设置

## 界面与外观

在 **设置 → 界面与外观** 中调整夜间模式、自定义字体和收藏夹展示。

<Screenshot src="/img/guide/appearance.png" alt="界面与外观设置" />

### 存档时间显示

- **精确时间（默认）**：完整日期和时刻，如 `2026-09-08 20:42:18`。
- **相对时间**：最近显示“刚刚”“8 分钟前”“2 小时前”，昨天显示“昨天 22:15”，更早显示日期。

悬停可查看精确时间。

## 设备管理

在 **设置 → 设备管理** 中修改设备名称、查看已连接的设备，或导入其他设备的路径配置。

具体操作见[存档位置与路径变量](./games/paths.md)。

# 云库、独立存档与路径变量

本次更新把云同步重做为**云库**，备份改为**标准 7z 独立存档**，并带来**设备级路径变量**、**按游戏自动备份**与全新的界面。

:::warning 升级前请先备份

旧版配置会自动转换，转换**不可逆**：升级后 1.8 无法读取新配置，请先完整备份。使用云同步时，请**先把所有设备都升级到 1.9**，再在其中一台设备上选择 **升级到新云库**；切换时保持应用运行，中断后可以继续。完整步骤见[升级到 1.9](/docs/help/upgrade)。

:::

## ✨ 核心功能亮点

- **☁️ 云库**：
    - 云同步界面重做，每台设备可以**按游戏**分别设置"手动 / 云备份 / 多设备同步"。
    - 其他设备有新进度时会提示**比较进度**，由你选择使用哪一份，不会自动覆盖本机存档。
    - 在存档列表里可以单条或批量上传、下载，也可以"全部下载到本机"。
    - 删除按范围区分：**移除本地副本**保留快照历史和云端副本；**从本机删除**只影响这台设备；**从云端和所有设备删除**与**从云库永久删除**无法撤销，离线设备重新连接后才会执行。
    - 新增**云加入码**：在另一台设备粘贴即可连接同一个云库（加入码含凭据，请勿分享）。
    - 新增**本地文件夹**作为云存储类型，S3 兼容存储支持 virtual-hosted 风格地址（腾讯云 COS、阿里云 OSS 等）。
    - 离线也能备份、恢复和修改描述，联网后在后台同步。

- **📦 独立存档（标准 7z）**：
    - 新备份是标准的 `.7z` 文件，内含 `RESTORE.txt`，**不用本软件也能手动恢复**。
    - 保留文件的时间戳与权限，支持恢复 Windows 隐藏和只读文件；注册表存档改为标准 `.reg`。
    - 旧 ZIP 备份依然可以正常恢复。

- **🔁 本地快照升级**（设置 → 备份设置）：把历史备份转换为新格式，可暂停后继续，原件保留到你点击清理。

- **🗂️ 设备级路径变量**：
    - 每个游戏在**每台设备**上可以分别设置游戏安装目录、游戏根目录和商店账号。
    - 某台设备的存档位置不同？用"覆写此设备路径"单独指定。
    - 支持 Ludusavi 的全部路径变量与 `*`、`?` 通配符；输入 `<` 即可选择变量并预览解析结果。
    - 新增自定义变量 `<var:名称>`，可按设备或按游戏定义，缺少变量时会引导你填写或查找本机位置。

- **⏱️ 自动备份与快捷备份**：
    - 定时备份改为**按游戏设置**，多个游戏可以同时定时备份，间隔可自定义。
    - 新增进程监控：游戏启动时、退出时或运行期间定时备份。
    - 自动备份的保留数量可以单独设置。

- **🎮 游戏库与导入**：
    - 可以随时修改已添加的游戏：改名、增删存档条目，同名文件不再冲突。
    - 同一个游戏可以再导入一次，作为另一个实例。
    - 可自动扫描视觉小说（Kirikiri2、Ren'Py、RPG Maker、Wolf RPG），并跳过 OneDrive 中尚未下载的文件。
    - 游戏可按上次游玩时间等排序。

- **🖥️ 界面**：设置页改为分组导航，"关于"并入设置；备份和恢复只弹一条结果通知；当前快照在列表中高亮，可切换相对时间显示；可以设置启动时显示"收藏夹"还是"全部"。

- **⬆️ 应用更新**：新增"启动时检查更新"（默认关闭）。Windows 安装版会在后台下载，"重启并安装"时才安装；便携版与 Linux/macOS 仍为手动下载。

- **🌐 其他**：设置中新增"本机 API"，可查看访问地址与管理 Token；文档站新增原生英文版。

## 🐛 Bug 修复

### 备份与恢复

- 恢复前的额外备份失败时，恢复会中止：当前存档不会被覆盖，界面会说明原因。只有游戏当前没有任何存档文件时，才会跳过额外备份。
- 每个新备份都会校验完整性，恢复前先检查，损坏的备份会被拒绝；设置中的"创建备份时计算完整性哈希"和"恢复前验证压缩包完整性"开关已移除。
- 同一个游戏的备份与恢复不再同时进行，自动备份会跳过正在恢复的游戏；备份和删除同时发生时不再丢失快照。
- 修复断电后可能留下空存档的问题，中断遗留的临时文件会自动清理。
- 本地快照升级：遇到磁盘已满或权限错误时会说明原因并停止，腾出空间后可以继续；被中断后重试会替换损坏的遗留文件；已删除快照对应的升级项会自动结束；历史备份在存储目录名升级后依然可以找到。
- 修复存档路径通配符在设置时能识别、快照时却识别不到的问题。
- 修复"先删除再恢复"模式下恢复失败不会撤销删除，以及撤销恢复部分失败时提示不准确的问题。
- 修复 Windows 上文件被短暂占用时写入失败。

### 云库

- 打开存档管理页不再触发同步，并先显示本机快照，不等云端刷新完成。
- 无响应的云端请求会超时，不再让同步一直卡住。
- 云端出错时给出可以照着操作的提示（检查网络或设置、重新连接、重建、刷新），不再显示带请求地址的英文原文。
- 云端暂时连不上时，同步概览仍列出这台设备已有的游戏并标为"检查中"，不再显示成 0 个游戏。
- 云库文件缺失时，会提示云库已损坏并引导"从此设备重建"，不会再当成空云库而清掉已有快照；重建不会删除云端已有的存档文件。
- 修复用本地文件夹作云存储时，写入中断会损坏云库，以及存档在其他磁盘时传输失败的问题。
- 某个游戏同步失败不再影响其他游戏；后台同步更改游戏后，自动备份和快捷操作会跟着更新。
- 修复保存设置时可能还原云库游戏配置的问题。
- 修复坚果云根目录不存在时无法创建云库。
- 在存档管理页中，"移除本地副本"需要先确认云端有该快照的副本；无法加载云端信息时，按钮会置灰并说明原因。
- 从本机删除已加入云库的游戏前，会提示有多少快照只保存在本机、尚未上传到云端；无法连接云端时只给出提示，仍可继续。

### 快捷操作

- 快捷备份和恢复失败时会提示，已删除的游戏会被跳过。
- 快捷操作完成后，对应游戏的存档管理页会自动刷新。

### 其他

- 修复游戏名含特殊字符时无法导入或打开。
- 修复便携版文件名缺少版本号（1.8.0 显示为 `RGSM_undefined`）。

## ⚠️ 升级须知

### 升级云库

- **切换后这台设备只使用新云库**：旧云库里的数据不会删除，旧版或降级后的程序仍可查看旧数据，但**看不到之后的进度**。仍在使用旧版的设备，之后产生的进度不会进入新云库。
- **切换前会列出不会迁入的内容**：旧云端配置里没有列出的游戏，其快照会留在旧文件夹、不会出现在新云库；只在这台设备上的游戏会继续在本机使用，云同步保持关闭。切换时旧存档包下载失败会自动重试。
- **可选择开启自动清理云库快照**：如果这台设备原来给某些游戏限制过自动备份数量，切换时会询问是否为这些游戏沿用这个数量。开启后，会从所有设备和云端永久删除更早的自动快照；当前进度和已保护的快照不受影响。不开启则不会清理任何快照。
- 已加入云库的游戏不再使用本机的自动备份数量限制，其旧快照只由自动清理云库快照管理，关闭本机云存储期间也不会在本机清理。

### 升级本机

- **已加入云库的游戏的历史备份保持 ZIP 格式**，不会被"本地快照升级"转换，继续正常同步；新备份使用 7z。
- **托盘菜单精简**：原"自动备份间隔"菜单（5/10/30/60 分钟与关闭）已移除，改为在游戏的备份设置中配置。
- **安装位置迁移**：旧设置中无法唯一对应游戏的位置，会保留在 **设置 → 自动扫描 → 尚未关联游戏的安装目录**，需要你确认。
- **旧配置文件**：升级后数据目录里只保留 `GameSaveManager.config.json.bak`（升级前的旧配置），需要回退旧版时改回 `GameSaveManager.config.json` 即可；使用过 1.9 测试版的用户，首次启动时旧配置文件也会改名为 `.bak`。各文件的作用见[数据备份与迁移](/docs/extras/json)。
- **使用过 1.9 测试版的用户**：测试版的配置不保证能升级；已有 1.9 云库的内部格式升级另行处理，见[升级到 1.9](/docs/help/upgrade)。
- **便携版为精简版**：本次提供的便携版不内置 Ludusavi 识别数据库，需要时可在设置中更新。

# Improving documentation

Click **Edit this page** at the bottom of a page to update it. Documentation lives in `apps/rgsm-docs` in the main repository and is maintained alongside the application.

Use short steps and screenshots that match the current interface. Omit sentence-ending punctuation from screenshot captions.

Chinese pages live in `docs/`; English pages follow the same structure in `i18n/en/docusaurus-plugin-content-docs/current/`. Update both when changing a guide.

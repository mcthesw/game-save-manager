# Reporting issues

[Open an issue on GitHub](https://github.com/mcthesw/game-save-manager/issues/new/choose) and include:

- Application version, operating system, and whether you use the installer or portable build.
- What you did, what you expected, and what happened.
- Steps to reproduce the problem and screenshots of errors.
- Logs from the relevant time, available through **Settings → General → Open log**.

For cloud sync issues, include the storage type, affected devices, and what happened on each device.

Hide credentials and personal information before sharing. If saves are missing, preserve local and cloud data first.

Feature requests are welcome in issues or [Discussions](https://github.com/mcthesw/game-save-manager/discussions). See [About](./about.mdx) for other contact options.

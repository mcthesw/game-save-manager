# Sync modes

import Screenshot from '@site/src/components/Screenshot';

Enable cloud sync for a game on the **Cloud sync** page, then click **Sync mode** to choose a mode.

| Mode | Purpose |
| --- | --- |
| Manual | Share snapshot records; upload, download, and restore manually |
| Cloud Backup | Automatically upload new snapshots |
| Multi-device Sync | Automatically upload new snapshots and prompt about available progress from other devices |

Each device can choose a mode for each game.

<Screenshot src="/img/guide/en/cloud-library.png" alt="Sync modes and snapshot copy locations" />

Cloud information refreshes at the configured automatic sync interval. Switching games reuses the information already loaded.

# Continuing on another device

import Screenshot from '@site/src/components/Screenshot';

## Save on the original device

1. Exit the game and create a snapshot.
2. Confirm that the file has uploaded. **Cloud Backup** and **Multi-device Sync** upload new snapshots automatically.

## Continue on the new device

1. [Connect to the same Cloud Library](../extras/cloud.mdx) and set the game's save locations on this device.
2. Open **Cloud sync** and click the game's **Compare progress** action.
3. Find the snapshot you want, click **Use this progress**, and confirm.
4. Wait for the restore to finish, then start the game.

<Screenshot src="/img/guide/en/progress.png" alt="Comparing device progress and choosing a snapshot" caption="Compare progress" />

Keep the game closed while applying progress. The application downloads and verifies the snapshot, then creates a safety backup of the existing local save.

## Both devices have new progress

Review descriptions and branch relationships in the comparison dialog. Choose **Keep this device** or **Use this progress**, or select **Decide later**.

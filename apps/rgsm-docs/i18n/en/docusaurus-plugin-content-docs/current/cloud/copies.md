# Copies and cleanup

## Upload and download

Use **Upload to cloud** or **Download to this device** beside a snapshot. Select multiple snapshots for batch actions.

| Copy location | Action |
| --- | --- |
| This device | Apply directly |
| Cloud | Download, then apply |
| Another device | Upload from that device, then download here |

## Remove copies

| Action | Scope |
| --- | --- |
| Remove from this device | Remove this device's backup file and keep its history |
| Remove cloud copy | Remove the cloud backup file and keep its history |
| Delete everywhere | Permanently delete the snapshot and its copies; offline devices apply the deletion when they reconnect |

Before removing a copy, confirm that another location has a usable copy.

## Clean up automatic snapshots

Set the **Automatic snapshots in the Cloud Library** in the game's **Auto-save settings** to permanently remove old automatic snapshots and their copies along each progress line.

Manual snapshots, quick-action snapshots, each device's current position, and protected snapshots are kept.

## Remove a game

**Stop managing here** keeps the snapshot history in the Cloud Library and existing backups. **Permanently delete from the Cloud Library** removes the game's snapshot history and copies on all devices and in the cloud.

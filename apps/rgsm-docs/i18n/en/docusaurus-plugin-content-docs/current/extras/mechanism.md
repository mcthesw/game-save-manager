# Branches and current progress

## View branches

Open a game and switch to **Branch View** to see how its snapshots relate.

For example, save A, B, and C in order, then restore A, keep playing, and save D. This creates two progress lines:

- A → B → C
- A → D

Click a node to view and manage its snapshot.

## Current progress

The highlighted row is the snapshot most recently created or applied on this device. After playing further, create another snapshot to save the new progress.

Each device has its own current position. Use [cloud sync](../cloud/progress.mdx) to compare and continue another device's progress.

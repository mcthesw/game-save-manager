# Adding and detecting games

import Screenshot from '@site/src/components/Screenshot';

## Add a game manually

1. Click **Add game** in the sidebar and enter a name.
2. Add save folders, files, or Windows registry entries.
3. Choose a game executable if needed, then click **Save**.

<Screenshot src="/img/guide/en/add-game.png" alt="Add Game panel" caption="A game can have multiple save locations" />

## Detect local games

1. Click **Detect local games** in the Add Game panel.
2. Search for and select games, then review the detected save locations.
3. Confirm the entries to import.

You can import several games at once. Update the detection database and add game library folders in **Settings → Auto Scan**.

## Scan visual novels

Add scan folders in **Settings → Auto Scan**, then click **Auto-scan VN** in the Add Game panel.

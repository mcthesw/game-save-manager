# Favorites and sorting

## Favorite games

In the sidebar's **All** list, click the star beside a game. Switch to **Favorites** to see it.

Use the favorites toolbar to add folders and games. Click the edit button to reorder items or move them into folders by dragging.

## Sort games

1. Open **Settings → Game order**.
2. Choose a sorting method and direction.
3. For the default order, drag games into place and click **Save default order**.

## Display preferences

In **Settings → Interface & Appearance**, choose whether favorites expand by default, whether new games are favorited automatically, and whether favorites and sorting are local or shared.

# Hidden or read-only files fail to restore

Version 1.9 supports restoring Windows hidden and read-only files and their attributes.

If a restore fails:

1. Exit the game.
2. Open **View managed files** and check the save locations.
3. Read the error in the activity panel and confirm that the destination folder is writable.
4. Preserve the original saves and [report the issue](../issues.mdx) with logs.

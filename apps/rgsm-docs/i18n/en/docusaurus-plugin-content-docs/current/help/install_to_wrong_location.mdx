# Installed in the wrong location

If you installed the application on the desktop, in Downloads, or inside another application's folder:

1. Quit Game Save Manager from the tray.
2. [Back up your configuration and saves](../extras/json.md), keeping other files in the same folder.
3. Reinstall into a dedicated folder, such as `D:\Apps\GameSaveManager`.
4. Check that your game list and backups work, then remove the old application files.

Keep application data when uninstalling.

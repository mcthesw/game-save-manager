# Automatic backups

import Screenshot from '@site/src/components/Screenshot';

Open **Auto-save settings** from the game's top-right menu.

## Timed backups

1. Enable **Auto Backup**.
2. Choose the interval and maximum number of timed backups. Leave the limit empty to use the global setting.
3. Click **Save settings**.

## Back up when the game runs

1. Enable **Process monitor** and select the game process.
2. Select **On start**, **On exit**, or **While running**.
3. Set an interval if needed, then click **Save settings**.

<Screenshot src="/img/guide/en/automatic.png" alt="Timed backups and process monitoring in Auto-save settings" />

A green dot before a game in the sidebar means automatic backups are enabled. Keep Game Save Manager running to use them.

For shared cloud retention, see [Copies and cleanup](../cloud/copies.md).

# Creating and restoring snapshots

import Screenshot from '@site/src/components/Screenshot';

## Create a snapshot

Select a game, enter a description, and click **Create new snapshot**. Search descriptions or sort by the date column to find a snapshot.

<Screenshot src="/img/guide/en/snapshots.png" alt="Snapshot list" caption="The current snapshot is highlighted in the list" />

## Restore a snapshot

1. Exit the game.
2. Click **Apply** beside a snapshot or **Apply latest** at the top.
3. Confirm the restore, then restart the game.

Use the buttons beside a snapshot to edit its description or delete it. Select multiple snapshots for batch actions.

## Extra backups

An extra backup is kept before restoring by default. Open **Extra backups** from the game's top-right menu to recover one.

Extra backups stay on this device. Each game keeps five by default; set the limit to zero to keep all of them.

## Backup settings

In **Settings → Backup settings**, configure restore confirmations, extra backups, compression, and hash verification.

<Screenshot src="/img/guide/en/backup-settings.png" alt="Backup settings" />

Store uses no compression, Fast favors speed, Standard is the default, and Best favors smaller files. These settings apply to newly created snapshots.

# Hotkeys and system tray

## Set up quick actions

1. Open **Settings → Quick Actions** and choose a game.
2. Set hotkeys for backup and restore.
3. Click the save button.

The same page controls notifications and sounds. You can choose and preview a custom sound.

## Tray actions

Right-click the Game Save Manager tray icon to back up or restore the selected quick-action game, or to quit the application.

**Minimize to tray** is enabled by default, so closing the window keeps the application running in the background. Use the tray menu to quit completely.

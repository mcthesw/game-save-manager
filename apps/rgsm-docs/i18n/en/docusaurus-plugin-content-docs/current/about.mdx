# About

## About Game Save Manager

Game Save Manager began as a small tool for managing my own Elden Ring saves. I added features at my roommates' request, and we used it to farm runes around the game's launch. After hearing about a bug that could corrupt other players' saves, I released the tool publicly.

It has since grown into an open-source project with more features. I hope it helps more players. You can contribute code on GitHub, suggest improvements through issues, or help write this site's documentation.

# 云端同步端到端测试

`pnpm web:e2e`

## 升级中断后恢复

升级开始、迁完第一份存档后被打断，旧云端数据应原样保留。

- 重启后能接着完成升级
- 再重启不产生重复存档
- 旧的上传方式被拒绝

## 两台设备先后升级再协作

1. 两台都还在旧云端，A 把存档发给 B
2. A 先升级，B 留在旧云端，B 被提示加入
3. B 保留云端数据加入，两台都上了新云端，旧上传方式被禁用
4. A 发布新存档，B 收到那一份
5. A 改同步模式，不影响 B
6. 两台从同一份存档各自分叉，A 必须明确选择 B 那条
7. 删除当前存档回退到上一份，另一台设备不得把它复活
8. 两台都重启后状态一致

## 两台设备互不干扰

两台设备的身份和流量完全隔离，互不影响。

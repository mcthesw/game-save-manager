# Model each Game as one instance per Device

Each Game represents one instance on each Device and can contain multiple Save Units; separate accounts or installation instances are separate Games, even when they share a title or store identity. Device-wide libraries and accounts supply discovery candidates, while the Game Device Binding owns the selected installation, account context, and game-specific path values. Apply relates captured data to the same Game and Save Unit on the target Device and uses that Device's current binding; device-local resource identifiers and generic mappings between multiple source and target instances do not establish save identity. This replaces ADR-0002's globally registered installation requirement and ADR-0004's persistent multi-source restore rules while retaining real wildcard matches within one instance.
